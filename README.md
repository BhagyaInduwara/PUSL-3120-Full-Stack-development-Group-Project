# FlowERP

FlowERP is a small-business ERP system with a Kanban-style Sales &amp;
Orders board, plus invoicing, inventory, shipments, and production
tracking — built with Next.js, Express, and MongoDB.

## How to run

```bash
npm install
cp .env.example .env   # fill in AUTH_SECRET at minimum — see comments in the file
npm run dev             # http://localhost:3000
```
